# Srinath Bhuvanapalli - Personal Portfolio

This repository contains the digital headquarters of **Srinath Bhu** — a Content Strategist, Organic Growth Specialist, Digital Storyteller, Video Producer, and Creator.

## Overview
This is a bespoke, scrapbook and editorial-style portfolio website designed to communicate storytelling, creativity, and strategic thinking. It features rich paper textures, hand-crafted aesthetic touches, responsive layout, and an evergreen philosophy ("Make the noise make sense").

## Tech Stack
- HTML5
- Modern CSS3 (Custom design system, light/dark themes, responsive CSS Grid and Flexbox)
- Vanilla JavaScript
- Google Fonts (Bricolage Grotesque & Caveat)

## Features
- Fully Responsive Design (mobile navigation, accessible drawer)
- Dynamic Light/Dark Mode with local storage persistence
- Animated number counters & scroll reveal effects
- Interactive tools ticker with pause/resume controls
- SEO & OpenGraph meta tags

## Local Development
To run this project locally, you can use any standard local web server (e.g., Live Server in VS Code, or Python's `http.server`):
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your browser.
